# Vídeos para aprender

Vídeos de YouTube encontrados para mejorar el canal. Claude no puede ver los vídeos: los
elige por el título, el canal y lo que dicen de ellos las búsquedas. Si alguno no te sirve,
díselo y busca otros. La sesión de cada noche añade 2 o 3 nuevos arriba.

## Guion y ganchos (lo más importante)

- [How To Write A Killer Script That Keeps Viewers Hooked](https://www.youtube.com/watch?v=7I50PECz7SU)
  — cómo planear el vídeo antes de escribir y un gancho en 5 partes. En inglés: activa
  los subtítulos traducidos (rueda ⚙ → Subtítulos → Traducir automáticamente → Español).
- [How to Write a YouTube Script that Gets More Views!](https://www.youtube.com/watch?v=RNXpLNcl6mo)
  — estructura de guion para que la gente no se vaya.
- [Screenwriting: How To Write A STRONG HOOK](https://www.youtube.com/watch?v=q8HrUXES1tA)
  — cómo escribir un gancho fuerte, desde el oficio de guionista.

## Títulos y miniaturas

- [The Untold Truth About YouTube Titles](https://www.youtube.com/watch?v=hHPdzYf0Qso)
  — títulos cortos, claros y que despierten emoción.
- [Las nuevas reglas de YouTube, de Paddy Galloway](https://www.colinandsamir.com/resources/the-new-rules-of-youtube-from-paddy-galloway)
  (artículo de Colin and Samir) — el consultor de MrBeast resume qué funciona hoy.

## Estilo documental faceless

- [MagnatesMedia Editing Tutorial - This Documentary Style is Going VIRAL!](https://www.youtube.com/watch?v=uoK-ZNmOVjM)
  — cómo se edita el estilo de MagnatesMedia (mapas, archivo y narración).
